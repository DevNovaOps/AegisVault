AegisVault Zero-Knowledge Cryptographic Boundary

AegisVault operates strictly on a mathematical Zero-Knowledge Architecture. By design, our server infrastructure, database instances, and administrators are technically and mathematically incapable of accessing user vault payloads.

Client-Side Key Generation Keys are derived on the user's local browser device via PBKDF2 + Argon2id. The master decryption key is never transmitted across the network.
Shamir's Secret Sharing (SSS) Vault recovery keys are split into polynomial threshold shares (k-of-n) distributed across independent, verified trustees.
AES-256-GCM Envelope Encryption All private files are encrypted with authenticated AES-256-GCM prior to replication to cold storage.
Time-Locked Grace Period Autonomous heartbeat timers protect owners from premature claim triggers with immutable grace periods.
