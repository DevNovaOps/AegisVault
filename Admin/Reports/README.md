# AegisVault — Reports & Custody Audit Module

## 1. Overview & Purpose
The **Reports Module** (`Admin/Reports/`) is an administrative reporting and analytics dashboard for the **AegisVault** Digital Asset & Legacy Custody Protocol.

It allows administrators and compliance officers to:
- Monitor historical vault activities, trustee shard splits, and verification countdown events.
- Audit cryptographic security incidents, brute-force mitigations, and WebAuthn authentications.
- Visualize trend lines of report generation velocity over custom windows (7 Days, 12 Days, 30 Days).
- Analyze distribution breakdowns across categories (User Activity, Security Events, Vault Operations, System Health, Compliance) via interactive SVG charts.
- Generate custom on-demand reports and schedule automated periodic dispatches.
- Inspect detailed cryptographic checksums (`SHA-256`) and download raw reports in multiple formats (**PDF**, **CSV**, **Excel**, **JSON**).

## 3. Key Architecture & Features

### A. Dual Theme System (Light & Dark)
- Built directly upon AegisVault's shared design tokens:
  - **Light Theme**: `#F4F6FA` background with clean card elevations and `#E86326` accents.
  - **Dark Theme**: `#020B11` deep midnight background with subtle border outlines and `#F5A84B` golden accents.
- Synchronized across browser sessions via `localStorage` (`aegisvault_theme`).
- Re-renders SVG charts and gradients dynamically when the theme is toggled.

### B. Pure SVG Vector Charts (Zero Bulky Dependencies)
- **Report Generation Trend**:
  - Pure SVG vector line chart utilizing cubic Bezier curves (`C`) and dynamic gradient fills.
  - Responsive coordinate mapping with interactive hover tooltips displaying date and count.
  - Period selector: *Last 7 Days*, *Last 12 Days*, *Last 30 Days*.
- **Reports by Type Donut**:
  - Computed circular donut arcs with percentage splits and a central counter (`28 Total Reports`).
  - Color-coded interactive category legend.
- **Report Status Donut**:
  - Visual breakdown of completed, generating, and failed report tasks with center counter (`28 Reports`).

### C. Live Search & Multi-Criteria Filtering
- **Category Tabs**: *Overview*, *User Reports*, *Security Reports*, *Vault Reports*, *System Reports*.
- **Search**: Instant filtering by report name, generated by author, or type.
- **Select Dropdowns**: Filter by Type and Execution Status.
- **View All**: Reset button restoring complete audit history.

### D. Client-Side Exports & Printing
- **Format Cards (PDF, CSV, Excel, JSON)**:
  - **CSV / Excel**: Generates standard RFC 4180 CSV strings and triggers native browser downloads via `Blob` and `URL.createObjectURL()`.
  - **JSON**: Produces formatted JSON payloads for external SIEM integration.
  - **PDF / Print**: Integrates with `@media print` to produce a clean, printer-friendly summary hiding unnecessary navigation elements.

## 4. Viva / Examination Talking Points
1. **Zero-Knowledge Principle**: The UI only displays anonymized audit metadata, event counts, and cryptographic hashes (`SHA-256`). Raw customer locker payloads remain encrypted client-side.
2. **Vanilla Lightweight Stack**: Uses Vanilla HTML5, CSS3, and JavaScript without bloated frameworks, ensuring maximum performance, zero build-step overhead, and fast demonstration startup.
3. **Responsive Design**: Fluid flexbox and CSS grid layouts with breakpoints at `1200px`, `900px`, and `768px` for mobile drawer navigation.

## 5. Future Backend / Django Integration
The JavaScript controller is built around an isolated mock dataset. To connect this module to a Django backend in the future:
1. Replace `this.reportsData = [...window.AegisReportMockData.reportsList]` in `report.js` with:
   ```javascript
   async fetchReports() {
       const response = await fetch('/api/v1/reports/', {
           headers: { 'Authorization': `Bearer ${getAuthToken()}` }
       });
       this.reportsData = await response.json();
       this.renderReportsTable();
   }
   ```
2. Replace `handleGenerateReportSubmit()` with a `POST /api/v1/reports/generate/` call triggering a Celery background worker to compile the requested report.
